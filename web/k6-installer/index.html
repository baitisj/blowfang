blowfang K6 installer

Installs blowfang on a Baofeng UV-K6 / K61 over its USB programming cable, right from this page. It does what tools/k6_install.py does, without Python. The instruction book is docs/manual/install.md: read its Before you start first, because flashing replaces the stock firmware for good.

This browser can't reach a serial port

Web Serial works in Chrome, Edge and Opera on a desktop or laptop (Windows, macOS, Linux, ChromeOS). Firefox, Safari and phones don't have it. Open this page in one of those browsers, or use tools/k6_install.py.

1 Your key

The radio runs only modules signed with your own key, so nobody else can load code into it. This page makes the key on your computer and never sends it anywhere: it writes the key into each image just before flashing and signs each module with it as it goes over the cable. Keep the key file: a radio keyed with it takes only modules signed with it. A key made by k6_install.py key works here too.

No key yet.

2 The release

The release folder blowfang-k6-…, from a blowfang release or the newest K6 pager firmware run on GitHub (artifact blowfang-k6-<commit>). Choose its zip as downloaded, or the unzipped folder. Every file is checked against the release's manifest before anything is sent.

No release chosen.

3 The radio

Plug the cable into the radio's two-pin socket, all the way in, and switch the radio on. On a radio that already runs blowfang, leave it in EXPLORE (or the arena). Then pick the cable's port: it is usually named CH340, CP210x, PL2303 or "USB Serial".

Not connected.

4 Install

On a new radio this asks you to switch it off and on three times and to press MENU once; it never asks you to hold keys. On a radio that runs blowfang it updates with no hands.

Single steps

Load library: EXPLORE's pages, the help deck and the modules into a radio that runs the release's image. Flash one image: keys any blowfang .bin with your key and flashes it (on a blowfang radio with no hands, otherwise as you switch it on).
